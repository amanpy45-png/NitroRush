# NitroRush

A simple 2D racing game built with **Python, Pygame, and Object-Oriented Programming (OOP)**.

The goal is simple: control your car, avoid incoming enemy cars, and survive as long as possible while increasing your score.

---

## Features

* Player-controlled racing car
* Enemy cars
* Simple racing track
* Left and right movement
* Collision detection
* Score system
* Enemy car respawning
* Road boundary restriction
* Object-Oriented design

---

## Tech Stack

* **Python 3.12**
* **Pygame**
* **Object-Oriented Programming (OOP)**

---

## How to Play

1. Start the game.
2. Control the red player car using the **Left** and **Right** arrow keys.
3. Avoid the incoming enemy car.
4. Every time the enemy passes you, your score increases.
5. If your car hits the enemy, the game ends.

---

## Core Focus

NitroRush was created as a small project to practice **Object-Oriented Programming in Python** while building something interactive.

The main focus is understanding how classes and objects can be used to organize a real application.
